D3 Modeling Note: baseline vs. logistic regression vs. decision tree

Dry run. The 12 profiles are invented placeholders and all relevance ratings were assigned by Claude, not human reviewers. Treat the numbers as a test of the pipeline, not as the D3 result.

1. Setup

Task: rank upcoming campus events for a student who gives interests, optional free text and saved events. Data: two public feeds, the Niner Engage RSS feed (410 events) and the Campus Events calendar feed (683 events), normalized by the repository's pipeline into 1093 records. Candidate pool per profile: active events starting within 14 days of 2026-11-15 (558 events: 280 Campus Events, 278 Niner Engage; 255 distinct recurring groups), minus the 6 events in the frozen two-source test split, with cross-source duplicates collapsed. Judgments: the top 12 of several rankers pooled, shuffled and rated 0/1/2 (462 ratings). A row is a (profile, event) pair; label = rating ≥1, unjudged = 0.

Features, all known at prediction time: topic overlap with the profile, saved-topic similarity, TF-IDF cosine of profile text vs. event title and description (vocabulary fit on past events only), days ahead, description length, number of topic tags, recurring-group size, free food/admission tags, start hour and weekday. Ingestion timestamps, content hashes and ratings are never features; keyword tags are features, never labels.

Validation: leave-one-profile-out, with hyper-parameters tuned by profile-grouped CV inside the training profiles only (logistic regression C in {0.01, 0.1, 1}; tree max depth in {2, 3, 5}, min leaf in {5, 20}). Metrics: nDCG@10 (primary), recall@10, precision@10, category and organizer coverage in the top 10; 95% bootstrap CI over profiles (seed 0).

3. Selected model

Logistic regression has the higher mean nDCG@10 (0.392 vs 0.361) and is also the simpler model, so the rule "choose the simplest model within one standard error of the best" selects it without a tie-break. The gap (0.031) is smaller than one standard error (0.065) and the intervals overlap heavily, so the two are not clearly separated. Logistic regression also leads on the grouped-event check (0.437 vs 0.397) and on the week-later window (0.396 vs 0.304). Both are far above the baseline (0.063).

Other approaches were also tried. The existing recommend.py heuristic (0.499) and a zero-shot sentence-embedding similarity ranker (0.660) both scored higher than either model here, and a TF-IDF similarity ranker fit on past events only scored 0.202. So these are the simplest learned models compared here, not the best-scoring approach found.

5. Limitations

  • Placeholder profiles and model-assigned ratings; no human agreement estimate. The earlier Niner-Engage-only ratings were reused for events that stayed in the pool.
  • Only 12 profiles; wide CIs, and the logistic regression vs. tree gap is within noise.
  • Campus Events items almost never name an organizer (99% empty), so organizer coverage and top-organizer share are unreliable. Campus Events titles carry an "at <venue>" suffix that is stripped only for the recurring-group key.
  • Unjudged events count as 0 and the judged set was pooled from other rankers, so recall and precision cover judged items only.
  • Two 14-day windows from one snapshot; no interaction data, so no attendance or satisfaction claim.
  • The frozen split was fixed on an earlier snapshot and most of its test IDs are Campus Events (170 of 179 present); 6 events in the first window are excluded and never rated. Events newer than the split are unassigned.
